# VeilAI 产品文档

> 面向：达叔、未来协作的 Agent。用户看不懂技术细节，这份文档用人话讲清楚产品是什么、卖给谁、怎么赚钱。

## 一句话定位

VeilAI 是一个浏览器插件：在你跟 ChatGPT / Claude 聊天时，自动把消息里的个人敏感信息（邮箱、电话、卡号、姓名等）换成占位符再发出去，AI 只看到占位符；回答回来后，在你的屏幕上自动还原成真值。你看到的是原文，对方服务器收到的是脱敏版。

## 解决什么问题

- 手滑发隐私：聊天时顺手粘贴了手机号、邮箱、身份证号、银行卡，自己没意识到。
- 企业合规焦虑：员工用 AI 工具时把客户资料、内部信息发出去了。
- 现有方案要么太重（企业级 DLP），要么没有（靠自觉）。

VeilAI 的定位是**防误发**，不是军工级隐私保证。宣传口径只能说"帮你减少误发个人信息"，不能说"保证不泄露"。

## 目标用户

1. 欧美职场人士：日常用 ChatGPT / Claude 处理工作，偶尔粘贴含个人信息的文本。
2. 自由职业者 / 小团队：处理客户资料，怕泄露担责任。
3. 隐私敏感的个人用户。

第一版只做英文市场，只认英文格式的个人信息。

## 功能清单

### 免费版（核心）
- 自动识别并遮蔽：邮箱、电话（国际/US/UK）、银行卡（Luhn 校验）、IBAN、美国 SSN、中国手机号/身份证/银联卡（结构化格式）。
- 姓名识别：提示词后的姓名（My name is…）、称谓后的姓名（Mr.…）、标签后的姓名（name:…），以及同一名字在文中的重复出现。
- 地址、生日、证件号、IP。
- 发送前 toast 提示遮蔽了几处；页面上占位符自动还原显示。
- 自定义：加白名单、加自己的关键词规则。

### Pro（规划中，未开发）
- 团队策略包：统一脱敏规则下发。
- 审计日志：谁在什么时候发了什么类型的信息（只记类型不记内容）。
- 更多站点：Notion AI、Gemini、Copilot 等。
- 文件脱敏：PDF / 图片里的文字识别后遮蔽（现阶段只做"拦下+提醒"）。

## 诚实声明（写进商店描述和官网）

- 只能防"误发"和正常情况下的泄露，防不了恶意网页专门针对插件的攻击。
- 没有提示词的裸姓名（如"张三昨天来电话了"）识别不了。
- 浏览器里发 PDF / 图片：直接拦下提醒，不放行。
- 出错时默认拦下不发送，宁可误拦不错放。

## 风险

- OpenAI / Anthropic 改 API 路径或请求格式 → 插件失效要跟修（这是浏览器插件的通病）。
- Chrome 商店审核对"读取网页内容"类扩展较严，需要隐私政策页（上架前必须准备）。
