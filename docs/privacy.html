AliasChat Privacy Policy

Last updated: October 4, 2026

AliasChat is a browser extension that masks personal data in messages before they are sent to claude.ai or ChatGPT, and restores the real values on your screen. This policy explains what data AliasChat handles and how.

Data Collection

AliasChat collects no data. There is no server, no account, no analytics, and no telemetry. The extension makes no network requests of its own.

How Masking Works

When you send a message on claude.ai or chatgpt.com, AliasChat scans the message text in your browser tab for patterns that look like personal data (email addresses, phone numbers, payment card numbers, ID numbers, names, addresses, and similar). Each detected match is replaced with a placeholder before the message leaves your browser.

Limitations: Detection is pattern-based and cannot guarantee all personal data is caught. A bare name in free text with no title, label, or matching email nearby may not be detected. PDF and image uploads are blocked by default because their contents cannot be inspected in the browser.

The mapping between placeholders and real values is kept in the browser's session storage, which is not accessible to web pages. It is never sent anywhere and is discarded when the browser closes.

Optional Configuration

AliasChat has an options page where you may provide custom detection rules in JSON format. If you save configuration, it is stored using the browser's chrome.storage.sync API, which syncs through your own browser account (e.g., your Google account) according to your browser's sync settings. AliasChat's developers never see this data.

Permissions

AliasChat requests a single permission, storage, solely to save the optional configuration described above. It uses content scripts on https://claude.ai/*, https://chatgpt.com/*, and https://chat.openai.com/* only — the minimum needed to rewrite chat requests before sending and to restore placeholders in the rendered page.

Third-Party Services

AliasChat does not embed any third-party SDKs, trackers, or advertising. When you use claude.ai or ChatGPT, those services' own privacy policies apply to the (masked) data they receive.

Open Source

AliasChat is open source under the MIT License. You can inspect exactly what the extension does at github.com/yhdhappy/AliasChat.

Contact

For privacy questions, open an issue at github.com/yhdhappy/AliasChat/issues.

Changes

If this policy changes, the updated date above will be revised. Continued use of the extension after a change constitutes acceptance of the new policy.
